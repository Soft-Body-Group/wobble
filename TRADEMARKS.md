# Trademarks

Wobble's code is free software under the GPL (see [LICENSING.md](LICENSING.md)).
The GPL licenses the code. It does not license the **Wobble** name, the
logo or the app icons (`app/icons/`), which belong to Soft Body Group.

## What you may do without asking

- Distribute **unmodified** builds of Wobble under the name Wobble, with
  its icons.
- Say that a plugin, addon, script or tool is "for Wobble" or "works with
  Wobble", so long as nothing suggests that Soft Body Group made, reviewed
  or endorses it.
- Use the name in plain text to refer to the project, in articles,
  tutorials, talks, packaging metadata and the like.

## What needs a different name

- **Modified builds and forks.** If you distribute Wobble with changes to
  its code, give it a name and icon of your own and do not call it Wobble.
  Saying that it is "based on Wobble" is fine.
- Anything that could be mistaken for an official Wobble release, website,
  store or service.

## Questions

Open an issue on the project's repository if you are unsure whether a use
is fine. The answer is usually yes.
